# Contributing to the Akili Ecomuseum Network (AEN)

Thank you for your interest in contributing to the **Akili Ecomuseum Network (AEN)**—Africa's first open-access, digital Highland-to-Ocean (Ridge-to-Reef) ecomuseum network. 

As an autonomous Digital Public Good, AEN relies on decentralized contributions from researchers, marine scientists, indigenous knowledge keepers, Beach Management Units (BMUs), riverine communities, and open-source software developers across Kenya and globally.

---

## 1. Core Principles & Standards

1. **Digital Public Good**: All documentation, datasets, and codebase updates contributed to this repository are placed in the digital public domain or licensed under open-access frameworks.
2. **Licensing**: All community-submitted narrative content, geospatial data, and research archives are governed by the **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)** license.
3. **Indigenous Data Sovereignty**: Oral histories, local ecological knowledge (LEK), and Swahili maritime traditions remain the perpetual cultural property of their origin communities. Contributions must respect community consent and attribution protocols.
4. **Academic Priority & Provenance**: All master releases are indexed under CERN/Zenodo (Master DOI: `10.5281/zenodo.23180750`).

---

## 2. Ways to Contribute

### A. Ecological & Field Data
We welcome contributions covering the 9 core corridor nodes across Kenya (from Mount Kenya Headwaters to the Lamu Archipelago):
- Hydrological monitoring data (river discharge, siltation, reef health, mangrove canopy coverage).
- Biodiversity observations and species inventories.
- Geospatial mapping boundaries (`.geojson` or `.json` formats).

### B. Cultural & Oral Histories
- Transcripts, audio recordings, or summaries of Swahili maritime heritage, traditional dhow building, and indigenous water management systems.
- Community-led conservation initiatives and local Beach Management Unit (BMU) records.

### C. Technical & Codebase Improvements
- Frontend design and user experience updates for `index.html`.
- Structured metadata enhancements (Schema.org / JSON-LD).
- Data schema updates in `nodes.json`.

## 3. How to Submit Contributions

### Option 1: GitHub Discussions (Non-Technical / Community Submissions)
If you do not use Git or GitHub code tools:
1. Navigate to the **Discussions** tab on the Akili Ecomuseum GitHub repository.
2. Select the relevant node category (e.g., *Node 07 • Kilifi & Watamu Reefs*).
3. Post your research links, community stories, or field notes directly.

### Option 2: Pull Requests (Code & Structured Data)
1. **Fork** the repository: `https://github.com/akiliecomuseum-sys/akili-ecomuseum`
2. Create a feature branch for your update (`git checkout -b feature/node-data-update`).
3. Commit your changes with clear messages (`git commit -m "Added hydrology notes for Sabaki Estuary"`).
4. Push to your branch and open a **Pull Request (PR)** targeting the `main` branch.
